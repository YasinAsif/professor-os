# 10-Minute Pre-Demo Countdown Checklist

Execute this checklist 10 minutes before stepping up to the presentation podium.

---

## 1. Environment & Hardware
- [ ] Laptop connected to charger (do not run on battery alone).
- [ ] Windows notifications set to "Focus Assist / Do Not Disturb".
- [ ] Connect to venue projector/screen and verify display resolution (`Win + P` -> "Duplicate").
- [ ] Ensure mobile 4G hotspot is powered on and paired as backup Wi-Fi.

## 2. Server & Services
- [ ] Backend server running cleanly (`http://localhost:8000/docs` responds with 200 OK).
- [ ] Database accessible and connected.
- [ ] Frontend running (`http://localhost:3000`).

## 3. Browser Setup
- [ ] Window 1 (Normal Chrome): Logged in as Professor (`test@gmail.com`). Course page already open.
- [ ] Window 2 (Incognito Chrome): Logged in as Student (`student1@professoros.edu.pk`).
- [ ] Close all unnecessary browser tabs, personal messengers, and email clients.
- [ ] Close Developer Tools (F12) to avoid accidental anti-cheat triggers.

## 4. Emergency Fallbacks
- [ ] Backup screen recording video file located on desktop.
- [ ] Single-page `demo-disaster-plan.md` open on mobile phone.
